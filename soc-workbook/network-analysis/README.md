# Network Analysis – Nmap, tcpdump and Wireshark

This folder contains two practical exercises focused on basic network analysis.  
The goal is to capture, inspect and interpret network traffic using common tools such as Nmap, tcpdump and Wireshark. These exercises help build core skills for SOC and Blue Team workflows.

## Folder structure

- nmap-scan  
  Active scan performed with Nmap to identify hosts and basic information from the local network.

- tcpdump-wireshark  
  Traffic capture using tcpdump and protocol analysis using Wireshark.  
  Includes findings for DNS, TCP, TLS and HTTP.

## Purpose

The exercises in this folder demonstrate how to perform:

- Host discovery with Nmap  
- Packet capture from real network interfaces  
- Protocol filtering and inspection in Wireshark  
- Interpretation of common traffic patterns seen in normal browsing  
- Basic documentation of network behavior  

## Skills practiced

- Use of Nmap for host discovery  
- Packet capture using tcpdump  
- Protocol analysis in Wireshark  
- Understanding of DNS, TCP, TLS and HTTP behaviour  
- Identification of normal vs. unusual traffic  
- Documentation of findings for security analysis  

## Tools used

- Nmap  
- tcpdump  
- Wireshark  
- Linux terminal (Kali)
