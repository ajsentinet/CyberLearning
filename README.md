# CyberLearning – SOC Analyst Portfolio

This repository contains my practical cybersecurity projects and exercises.  
I use this space to learn and document skills related to SOC operations, log analysis, network traffic investigation, SIEM tools, and Python automation.

---

## Projects Included

### ▪ Port Scanner (Python – 3 versions)
Basic, advanced, and threaded versions of a port scanner.  
These scripts show my progress in network scanning, socket programming, and automation.

### ▪ Honeypot (Python)
A simple honeypot that simulates a fake service and logs connection attempts.  
Includes log analysis using Python and pandas.

### ▪ Nmap Automation
A Python script to automate Nmap scans and export results for later investigation.

### ▪ Network Analysis (tcpdump + Wireshark)
Traffic capture and PCAP investigation.  
Includes DNS, HTTP, User-Agent analysis, and findings with evidence.

### ▪ SIEM – Wazuh Labs
Exploration of Wazuh dashboards, alerts, detections, and rule interpretation.  
Includes SSH brute force, sudo misuse, and custom PCAP findings.

### ▪ System Logs Analysis
Review of Linux system logs, failed logins, sudo events, and suspicious activity.
